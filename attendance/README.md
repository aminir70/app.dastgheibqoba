# 📋 اپ حضور و غیاب

اپلیکیشن وب فارسی برای مدیریت **کلاس‌ها، دانشجوها و حضور و غیاب** — قابل اجرا به‌صورت
**کاملاً رایگان** روی Cloudflare Workers + دیتابیس D1.

## امکانات

- **تعریف و ویرایش کلاس و دانشجو** با ثبت‌نام دانشجو در چند کلاس
- **حضور و غیاب** با چهار وضعیت: حاضر / غایب / تأخیر / موجه (ذخیره خودکار هر تغییر)
- **قانون هفتگی کلاس‌های ورزشی:** برای هر کلاس ورزشی می‌توانید پیش‌نیاز تعریف کنید
  (مثلاً «قرآن» و «احکام»). اگر دانشجو در همان هفته (شنبه تا جمعه) در یکی از
  پیش‌نیازها غیبت غیرموجه داشته باشد، در جلسه کلاس ورزشی **قرمز (محروم)** نمایش
  داده می‌شود، همراه با دلیل و تاریخ غیبت.
- **گزارش‌گیری** بر اساس بازه تاریخ (شمسی)، کلاس و دانشجو + درصد حضور + **خروجی CSV**
- **چندکاربره:** حساب مدیر و مربی؛ مدیر می‌تواند کاربر بسازد و رمز عوض کند
- **تقویم شمسی** در همه‌جا؛ رابط راست‌به‌چپ بهینه برای موبایل و ویندوز (PWA — قابل نصب)
- داشبورد آمار: تعداد دانشجو، کلاس، جلسات و غیبت‌های هفته جاری

## راه‌اندازی روی Cloudflare (رایگان)

پیش‌نیاز: یک حساب رایگان [Cloudflare](https://dash.cloudflare.com/sign-up) و Node.js روی سیستم.

```bash
cd attendance
npm install                # نصب wrangler
npx wrangler login         # ورود به حساب کلودفلر (مرورگر باز می‌شود)

# ۱) ساخت دیتابیس D1
npx wrangler d1 create attendance-db
#    خروجی یک database_id می‌دهد؛ آن را در wrangler.toml جایگزین
#    REPLACE_WITH_YOUR_D1_DATABASE_ID کنید.

# ۲) ساخت جدول‌ها
npx wrangler d1 execute attendance-db --remote --file=schema.sql

# ۳) رمز امضای توکن‌ها (یک عبارت طولانی تصادفی وارد کنید)
npx wrangler secret put JWT_SECRET

# ۴) انتشار
npx wrangler deploy
```

آدرس اپ چیزی شبیه `https://attendance-app.<your-subdomain>.workers.dev` خواهد بود.
همین آدرس را روی موبایل باز کنید و از منوی مرورگر «Add to Home Screen» بزنید تا مثل اپ نصب شود.

### اولین ورود

دیتابیس در ابتدا خالی است. **اولین نام کاربری و رمزی که در صفحه ورود وارد کنید،
به‌عنوان حساب مدیر ساخته می‌شود** (رمز حداقل ۶ کاراکتر). بعد از آن از بخش
«مدیریت کاربران» در صفحه خانه می‌توانید برای بقیه حساب بسازید.

### اجرای محلی برای تست

```bash
npx wrangler d1 execute attendance-db --local --file=schema.sql
npx wrangler dev
# سپس http://localhost:8787
```

## نحوه استفاده

1. **کلاس‌ها ←** کلاس‌های عادی (قرآن، احکام، ...) را بسازید.
2. **کلاس‌ها ←** کلاس ورزشی (فوتبال، ...) را بسازید، تیک «کلاس ورزشی» را بزنید و
   پیش‌نیازهای هفتگی را انتخاب کنید.
3. **دانشجوها ←** دانشجوها را اضافه و در کلاس‌ها ثبت‌نام کنید (از هر دو سمت — فرم
   کلاس یا فرم دانشجو — قابل انجام است).
4. **حضور و غیاب ←** کلاس ← تاریخ جلسه (پیش‌فرض امروز) ← وضعیت هر دانشجو را با یک
   لمس ثبت کنید. لمس دوباره همان دکمه، وضعیت را پاک می‌کند. دکمه «همه حاضر» هم هست.
5. در جلسه کلاس ورزشی، دانشجویانی که آن هفته در پیش‌نیازها غیبت داشته‌اند با
   حاشیه قرمز و برچسب «⛔ محروم این هفته» و ذکر دلیل نمایش داده می‌شوند.
6. **گزارش ←** بازه تاریخ و در صورت نیاز کلاس/دانشجو را انتخاب و گزارش یا CSV بگیرید.

## نکات فنی

- تاریخ‌ها در دیتابیس میلادی (`YYYY-MM-DD`) ذخیره و در رابط کاربری شمسی نمایش داده می‌شوند.
- هفته از **شنبه تا جمعه** محاسبه می‌شود و برای محرومیت ورزشی، غیبت‌های از اول هفته
  تا تاریخ جلسه ورزشی بررسی می‌شود. غیبت «موجه» باعث محرومیت نمی‌شود.
- احراز هویت: توکن HMAC (مشابه JWT) با انقضای ۳۰ روز؛ رمزها با PBKDF2 هش می‌شوند.
- حذف دانشجو همه سوابقش را پاک می‌کند؛ برای حفظ سوابق، دانشجو را «غیرفعال» کنید.
- سهمیه رایگان Cloudflare (۱۰۰هزار درخواست در روز و ۵ گیگ D1) برای این کاربرد بسیار بیش از نیاز است.
